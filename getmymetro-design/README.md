# GetMyMetro design handoff

- `PROMPT.md`: what to paste into Claude Code
- `DESIGN.md`: the full design spec
- `tokens.css`: colours, type, spacing and motion as CSS variables
- `screens/`: screenshots of every screen
- `html/`: static reference pages; open them in a browser to inspect exact values

To use it:
1. Unzip this folder into the root of your project, so you have `your-project/getmymetro-design/`.
2. Open Claude Code in your project folder.
3. Paste the prompt from `PROMPT.md`.
